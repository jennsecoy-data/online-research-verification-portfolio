## Research Approach

For each project, I aim to:

1. Define the research question and required data points.
2. Prioritize authoritative and current sources.
3. Compare information across multiple sources.
4. Document inconsistencies, missing information, and limitations.
5. Record the date each source was reviewed.
6. Assign a confidence level when appropriate.
7. Present findings in a clear and usable format.
