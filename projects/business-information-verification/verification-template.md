## Verification Status Definitions

| Status | Definition |
|---|---|
| Verified | Supported by an authoritative source and requires no significant qualification |
| Verified with normalization | Supported by the source, but formatting was standardized for structured use |
| Verified with context | Supported by the source, but its meaning, purpose, or organizational relationship requires explanation |
| Partially Verified | Some elements are supported, but one or more details remain uncertain |
| Unable to Verify | Available sources do not provide enough reliable evidence |
| Conflicting | Authoritative sources provide materially different values that cannot yet be reconciled |

## Source Evaluation

Evaluate each important source using the following criteria:

- **Authority:** Who published or filed the information?
- **Accuracy:** Can the information be independently confirmed?
- **Currency:** Is it current enough for the research purpose?
- **Relevance:** Does it directly support the required data point?
- **Transparency:** Is the source’s ownership, evidence, or purpose clear?
- **Consistency:** Does it agree with other authoritative information?
